# Менеджер задач на React

Лабораторная работа № 3 на React 19, React Router и Vite. В приложении можно создавать списки, добавлять задачи и подзадачи, искать по названию, фильтровать по статусу и переключать тему. [Макет в Figma](https://www.figma.com/design/U09ssoBkhIpaSLmO5v0AQ7/To-Do-List-%28Community%29).

## Запуск

Нужен Node.js 20.19+ в ветке 20 или Node.js 22.12+.

```sh
npm ci
npm run dev
```

Откройте адрес, который покажет Vite.
