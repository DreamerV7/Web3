# Маршруты и модель данных

| Адрес | Экран |
| --- | --- |
| `/` | Главная. Приглашение создать или выбрать список |
| `/lists/:listId` | Страница списка |
| `/lists/:listId/tasks/:taskId` | Карточка задачи, вложенная в страницу списка |
| Остальные адреса | «Страница не найдена» |

Список и вложенная карточка используют параметр `filter=active` или `filter=completed`. Без параметра видны все задачи. Чужая задача в списке считается ненайденной, даже если такой идентификатор существует в другом списке. Поиск хранится в состоянии страницы списка и сбрасывается при смене списка.

Состояние `{ lists, tasks }` хранится под ключом `todo-app:v2`. Список содержит `{ id, title }`, задача — `{ id, listId, title, body, done, createdAt, subtasks }`, подзадача — `{ id, title, done }`. При первом запуске без записи v2 задачи из `todo-app:v1` переносятся во «Входящие».

| Действия | Результат |
| --- | --- |
| `list/added`, `list/renamed`, `list/removed` | Создание, переименование и удаление списка вместе с его задачами |
| `task/added`, `task/updated`, `task/toggled`, `task/removed` | Операции над одной задачей |
| `task/cleared` | Удаление выполненных задач текущего списка |
| `subtask/added`, `subtask/renamed`, `subtask/toggled`, `subtask/removed` | Изменение подзадач одной задачи |

Выполнение родительской задачи и подзадач независимо. Прогресс вычисляется по подзадачам.
