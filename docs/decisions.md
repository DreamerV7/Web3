# Решения по Л3

## Принятые решения

- Завершение задачи и её подзадач независимо. Оценка прогресса показывает только состояние подзадач.
- До 768 px панель списков открывается кнопкой «Списки». Escape закрывает её и возвращает фокус на кнопку. До 1050 px карточка заменяет список в рабочей области, а на широком экране открывается рядом.
- Поисковый запрос действует в пределах текущего списка и сбрасывается при смене списка. Адрес хранит только фильтр по статусу.
- Изменённые поля карточки сохраняются кнопкой. Ctrl/Cmd + Enter в описании тоже отправляет форму.
- Карточка закрывается по ссылке возврата, по Escape или по клику снаружи. При закрытии сохраняется фильтр, фокус возвращается на ссылку задачи. После удаления он переходит к соседней видимой задаче или к полю добавления.
- Первый выбор темы учитывает настройку системы. Кнопка показывает название текущей темы. Скрипт в `index.html` применяет тему до запуска React. Две палитры основаны на кремовом, коричневом и оранжевом цветах Л2.

## Перенос с Л2

Императивная отрисовка через шаблон задачи, `querySelector`, `replaceChildren` и делегирование событий уступили место JSX и обработчикам компонентов. Ключи React сохраняют элементы между обновлениями. Схема возврата фокуса осталась только для операций, при которых исходный элемент исчезает, и для переходов между маршрутами.

Если в том же источнике (схема, хост и порт) есть старое хранилище `todo-app:v1`, при первом запуске из него создаётся список «Входящие». Новые данные хранятся под ключом `todo-app:v2`.
