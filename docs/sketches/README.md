# Эскизы недостающих экранов

Сохраняются Roboto, тёплый тёмный фон, кремовый текст и оранжевые границы из Л2. Светлая тема использует кремовый фон и коричневый текст из той же палитры. В карточках виден текст кнопок.

Широкий экран, открыта карточка задачи

```text
┌──────────────────────────────────────────────────────────────────┐
│ Менеджер задач                                             Тема │
├───────────────┬───────────────────────────┬──────────────────────┤
│ Списки        │ Входящие       Управление │ ← К списку           │
│ Входящие   2  │ [Название  ]   [Добавить] │ Карточка задачи      │
│ Учёба      1  │ [Описание               ] │ [Название         ]  │
│ [Новый список]│ [Поиск                  ] │ [Описание         ]  │
│               │ Все  Активные  Выполн.    │ [Сохранить        ]  │
│               │ □ Прочитать методичку 1/3 │ Выполнено 1 из 3     │
│               │ □ Сделать эскиз           │ ■■■□□□□□□            │
│               │ 2 активные                │ ☑ Прочитать Л2       │
└───────────────┴───────────────────────────┴──────────────────────┘
```

Узкий экран

```text
┌────────────────────────────┐
│ Списки                Тема │
├────────────────────────────┤
│ ← К списку                 │
│ Карточка задачи            │
│ [Название                ] │
│ [Описание                ] │
│ [Сохранить               ] │
│ Подзадачи                  │
│ Выполнено 1 из 3           │
└────────────────────────────┘
```

По кнопке «Списки» открывается панель над рабочей областью в потоке страницы. На мобильном карточка заменяет содержимое списка. При пустом хранилище главная предлагает создать список. При пустом результате поиска в области задач показан запрос и кнопка «Сбросить поиск».
