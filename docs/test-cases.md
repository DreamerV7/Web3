# Сценарии проверки

Сценарии из методички дополнены проверками Л2 и миграции. Для повторения начните с нового профиля браузера, чтобы существующие списки не влияли на результат. Сценарии пройдены в Chromium через Playwright на Vite dev и preview. В консоли браузера не было ошибок и предупреждений, `npm run lint` и `npm run build` завершились успешно. Минимальный контраст среди проверенных пар текста и фона составил 5,50:1 в светлой теме и 7,04:1 в тёмной.

| № | Действие | Ожидаемый результат | Результат |
| ---: | --- | --- | --- |
| 1 | Создать список «Учёба», затем попробовать создать пустой список | Новый список открыт по собственному адресу. Пустое название вызывает ошибку | Пройдено |
| 2 | Добавить две задачи, в том числе название с HTML-разметкой, и открыть другой список | Счётчик первого списка равен двум. Задачи принадлежат первому списку, HTML отображается текстом | Пройдено |
| 3 | Выбрать «Активные», открыть карточку и перезагрузить | Открыты та же карточка и тот же фильтр | Пройдено |
| 4 | Открыть /lists/неизвестный и /lists/:listId/tasks/неизвестная | Показано сообщение о ненайденном списке или задаче | Пройдено |
| 5 | Открыть /abc | Страница «Страница не найдена» со ссылкой на главную | Пройдено |
| 6 | Добавить три подзадачи, отметить две, изменить название и удалить третью | Сначала в карточке 2 из 3 и в строке 2/3. После удаления в карточке 2 из 2 | Пройдено |
| 7 | Очистить название задачи и попытаться сохранить | Форма сообщает об ошибке. Сохранённое название не меняется | Пройдено |
| 8 | Набрать «ОТЧЁТ» в поиске по задачам | Результат появляется после паузы и учитывает выбранный фильтр | Пройдено |
| 9 | Получить пустой результат и нажать «Сбросить поиск» | Запрос очищен, фокус возвращён на поиск | Пройдено |
| 10 | С непустым поиском открыть другой список | Поле поиска пустое, отображаются задачи нового списка | Пройдено |
| 11 | Включить тёмную тему и перезагрузить карточку | Тёмная тема установлена ещё до запуска React | Пройдено |
| 12 | Переименовать текущий список, затем удалить его с подтверждением | Имя обновилось. После удаления открыта главная, задач списка нет в хранилище | Пройдено |
| 13 | Открыть подтверждение удаления и нажать Escape | Список сохранён, фокус возвращён на «Удалить список» | Пройдено |
| 14 | Открыть список, карточку и вернуться клавишей Enter | При открытии фокус на заголовке, при возврате — на ссылке задачи | Пройдено |
| 15 | Переключить два фильтра, нажать «Назад» и «Вперёд» в браузере | Значение фильтра совпадает с адресом на каждом шаге | Пройдено |
| 16 | Удалить задачу из карточки, отметить оставшуюся и очистить выполненные | Фокус переходит на соседнюю задачу, затем на поле добавления | Пройдено |
| 17 | Открыть карточку на 360, 768 и 1280 px | Горизонтальной прокрутки нет. На 360 px списки доступны по кнопке меню | Пройдено |
| 18 | Добавить старую запись v1, затем испортить запись v2 | Старая задача появляется во «Входящих». При повреждённой записи приложение открывается с пустыми данными | Пройдено |
| 19 | Выбрать «Поделиться» и «Копировать текст» | В буфере обмена название и описание задачи | Пройдено |
| 20 | Открыть список на ширине 390 px, удалить задачу кнопкой в строке | Поля формы высотой 32 px, кнопка «+» 70 × 70 px, между карточками 16 px. Escape отменяет удаление, после подтверждения фокус переходит к соседней задаче | Пройдено |
| 21 | Переключить тему дважды и перезагрузить страницу после выбора | Кнопка показывает «Светлая тема» или «Тёмная тема» в соответствии с текущим оформлением | Пройдено |
| 22 | Открыть карточку с фильтром, нажать внутри, затем снаружи. Повторить с Escape | Клик внутри оставляет карточку открытой. Клик снаружи или Escape возвращает к списку с тем же фильтром и фокусом на задаче | Пройдено |
