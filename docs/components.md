# Дерево компонентов

```text
StrictMode
└─ ThemeProvider (тема)
   └─ TodoProvider (списки, задачи и dispatch)
      └─ RouterProvider
         └─ Layout
            ├─ Sidebar
            └─ Outlet
               ├─ Home
               ├─ ListPage
               │  ├─ NameForm / ConfirmDialog (управление списком)
               │  ├─ TaskForm
               │  ├─ TaskFilters
               │  ├─ TaskRow × N
               │  └─ Outlet → TaskCard → TaskDetails
               │                            ├─ TaskForm
               │                            ├─ Subtasks → NameForm
               │                            └─ ConfirmDialog / Dialog
               └─ NotFound
```

| Компонент | Props | Собственное состояние и источники данных |
| --- | --- | --- |
| Layout | — | Открытие мобильной навигации. Тема из контекста, текущий адрес из Router |
| Sidebar | Открытие, закрытие и ссылка для фокуса | Списки из TodoContext. Счётчики вычисляются из задач |
| ListPage | Идентификатор списка | Строка поиска, окно переименования и подтверждения. Фильтр из URL, данные из TodoContext |
| TaskForm | Задача (для редактирования), обработчик сохранения, ссылка на поле | Название, описание, ошибка ввода |
| NameForm | Подпись, начальное значение, обработчик сохранения | Текст и ошибка ввода |
| TaskFilters | Выбранное значение и обработчик | — |
| TaskRow | Задача, адрес, признак выбора, обработчик отметки и ссылка для фокуса | — |
| TaskCard | — | Данные из контекста и параметры Router |
| TaskDetails | Задача и адрес списка | Диалог и уведомление. Редьюсер из TodoContext |
| Subtasks | Задача | Идентификатор редактируемой подзадачи. Черновики живут в NameForm, изменения отправляются в контекст |
| ConfirmDialog | Заголовок, пояснение, действия | Использует нативный dialog и возвращает фокус |
| NotFound | Заголовок и адрес возврата | — |
